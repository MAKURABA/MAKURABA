Publishing to GitHub

Publishing

First time (Termux or any computer)

  1. Install the tools: pkg install python git gh on Termux.
  2. Sign in once: gh auth login.
  3. Clone your repository and unzip the hub over it.
  4. In GitHub, set Pages to deploy from the main branch, root.
git clone https://github.com/YOUR-NAME/YOUR-NAME.github.io
cd YOUR-NAME.github.io
unzip -o makuraba-hub.zip

Every time

Edit in the editor, then publish. It rebuilds, commits and pushes in one step. The site updates about a minute later.

python3 hub.py publish "what changed"
