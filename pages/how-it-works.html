How the hub works

Systems

The whole site is two pages and one tool. The hub page lists everything; the template makes every other page; the tool keeps them in step.

The four parts

  • hub.json

    The single source of truth for the directory and every index list.

  • hub.py

    Builds the hub and every page, and serves the visual editor.

  • index.html

    The hub page: directory, index lists, living background.

  • template.html

    The one template every other page is made from.

The agreement

  1. hub.json says what exists and in what order.
  2. The tool writes only between marked regions, so everything else in your files is yours.
  3. A page is the template plus its content, so changing the template restyles every page.
