Linking cheat sheet

Linking

Links use double brackets. Each form below is shown as typed, then as the live link it produces.

  • [[spinning-cube]] gives spinning-cube
  • [[spinning-cube|the 3D cube page]] gives the 3D cube page
  • [[projects/makuraba]] opens a whole group: projects/makuraba
  • [[library]] opens a menu section: Library
  • GitHub Pages docs is a normal web link: GitHub Pages docs

A Link card block

If a link is wrong

The editor tells you when you save, and the words stay as plain text, so nothing silently points nowhere. Renaming a page's title is always safe: its file name and id stay the same, so links keep working.
