# χ-RCC

The χ-Reentrant Closure Calculus: Formal Reference

MAKURABA · Revised edition, aligned with the χ reference implementation

Status of This Document

This reference states the axioms, definitions and proven results of χ-RCC, and separates them from results that are still conjectural. Every proven result here has a computational witness in the reference implementation (§9). Results without a proof are labelled Conjecture and offered as a research program.

The calculus concerns discrete distinction systems: sets of elements and directed transitions between them. It makes no physical claims. Where its vocabulary echoes geometry or physics ("fiber," "flux," "balance"), the terms refer to graph structures and graph measurements as defined here, and nothing more.

1. Primitives

The calculus begins with two primitives.

The distinction domain is a non-empty set S. Its elements are distinctions: anything that can be told apart from something else.

The distinction relation is a binary relation D ⊆ S × S. We write x → y when (x, y) ∈ D, and read it as "x gives rise to y."

Two derived relations follow at once. D⁺, the transitive closure of D, holds between x and y when a path of one or more steps leads from x to y. D*, the reflexive–transitive closure, also allows paths of zero steps. From these we define, for each x ∈ S, the set of everything x can reach:

reach(x) = { y ∈ S : x D⁺ y },

and the set of everything that can reach x:

coreach(x) = { y ∈ S : y D⁺ x }.

For any subset P ⊆ S, the image of P is the set of all immediate successors of its elements:

D(P) = { y : x → y for some x ∈ P }.

2. Axioms

A1 (Closure). D is an endorelation on S: every transition begins and ends inside the domain.

A1 excludes external grounding. No distinction can be explained by reference to something outside the system. The philosophical consequence, developed in Book 0 §VII, is that there is no position outside the system from which to observe it.

A2 (Recurrence). There exists s ∈ S such that s ∈ reach(s).

Some distinction can return to itself. A2 excludes purely acyclic systems, in which every path leads strictly forward. It is the formal statement of Book 0's first line: something repeats.

3. Identity

Definition 3.1 (Identity relation). For x, y ∈ S, x ≡ y if and only if x D y and y D x.

Two distinctions are identical when each can reach the other. Because D* is reflexive and transitive, ≡ is an equivalence relation on all of S.

Definition 3.2 (Identity class). The identity class of x is [x] = { y ∈ S : y ≡ x }, the strongly connected component (SCC) containing x. The set of all classes is the quotient Q = S/≡.

Definition 3.3 (Recurrent class). A class C is recurrent if some element of C lies in its own reach. Equivalently, C contains at least one cycle: either a self-loop, or two or more mutually reachable elements. Classes that are not recurrent are transient.

A2 says exactly that at least one recurrent class exists.

Definition 3.4 (Invariance). A subset P ⊆ S is closed (D-invariant) when D(P) ⊆ P: no transition leads out of P.

Theorem 2 (Identity is induced). The relation ≡ is determined entirely by D. No primitive notion of identity is required.

Proof. Definition 3.1 uses only D, and D is constructed from D alone. ∎

4. The Fundamental Theorems

Earlier drafts claimed that the identity class of a recurrent element is always closed. That claim is false. Take S = {0, 1} and D = {(0, 0), (0, 1)}. The class [0] = {0} is recurrent, because of the self-loop, but D({0}) = {0, 1}, which is not contained in {0}. A recurrent class can have arrows that leave it. The theorems below replace the false claim with three correct statements.

Theorem 1 (Re-entry). Let s satisfy A2, and let P = reach(s). Then P is non-empty and closed: D(P) ⊆ P.

Proof. By A2, s ∈ reach(s) = P, so P is non-empty. Let p ∈ P and p → p′. Since s D⁺ p and p → p′, transitivity gives s D⁺ p′, so p′ ∈ P. ∎

P is the smallest closed set containing s. Once a distinction recurs, everything it gives rise to stays within a region that the system cannot leave. Book 0 §III describes this as "a place it cannot leave."

Theorem 1b (Closed recurrent class). Let s satisfy A2, and suppose P = reach(s) is finite and every element of P has at least one successor. Then P contains a recurrent class B that is closed: D(B) ⊆ B.

Proof. Contract each identity class within P to a single node. The resulting graph of classes, the condensation, is finite and acyclic, so it has at least one sink: a class B with no arrows leading to any other class. By Theorem 1, every successor of an element of B lies in P. Because B is a sink, every such successor lies in B, so D(B) ⊆ B.

Now take any b ∈ B. By hypothesis b has a successor, and that successor lies in B. If B has more than one element, its elements are mutually reachable, so B contains a cycle. If B = {b}, the successor must be b itself, giving a self-loop. Either way B is recurrent. ∎

Theorem 3 (Observation as fixed point). If C is a recurrent class that is closed, then D(C) = C.

Proof. D(C) ⊆ C because C is closed. For the reverse inclusion, let c ∈ C. Since C is recurrent, there is a cycle through c of length at least one. Every element on that cycle is reachable from c and reaches c, so it lies in C. Let p be the element immediately before c on the cycle. Then p ∈ C and p → c, so c ∈ D(C). ∎

Definition 4.1 (Observation). An observation is the selection of a closed recurrent class C, that is, a fixed point of the image map P ↦ D(P).

In the quotient Q, such a class appears as a node whose only outgoing transition returns to itself. Observation in this sense requires no observer outside the system. It is the system's own dynamics arriving at a region that maps exactly onto itself (Book 0 §VIII).

5. The Operator Algebra

Operators act on identity classes and change the structure of the system.

  • D (Differentiate), 1 → 2. A class splits into two distinguishable classes.
  • A (Absorb), 2 → 1, irreversible. Two classes merge asymmetrically. The merged class keeps the outgoing relations of its inputs, and the inputs are retained in the record as inactive.
  • C (Couple), 2 → 1, symmetric. Mutual reachability is induced between two classes. Coupling differs in kind from absorption: neither input subsumes the other, and the result is a relation between stabilities (Book 0 §V).
  • S (Suspend), 1 → 0. A class loses admissibility and becomes terminal. It is retained in the record, not deleted.
  • J (Interject), proposed. A differentiation whose daughter returns to its source: s → s′ → s. J creates a recurrent pair in a single step, so it is the constructive form of Axiom A2. J is admissible whenever D is, and it deforms the constraint field exactly as D does.

Persistence, the identity operation, is implicit: when no operator is applied, structure is unchanged.

Composition grammar. A sequence of operators is well formed only if the output arity of each step matches the input arity of the next. Two compositions are forbidden outright:

  • (S, A): absorbing a suspended class;
  • (S, C): coupling with a suspended class.

In each case the suspended class has nothing left to contribute.

6. The Constraint Field

Definition 6.1 (χ-field). Each element s carries a constraint field

χ(s) = (Adm(s), q(s)),

where Adm(s) ⊆ {D, A, C, S, J} is the set of operators currently admissible at s, and q(s) is the differentiation quota. The quota is either unlimited (written −1), exhausted (0), or a finite number of remaining differentiations.

Definition 6.2 (Admissibility). An operator X is admissible at s when X ∈ Adm(s). For X ∈ {D, J}, the quota must also not be exhausted: q(s) ≠ 0.

Definition 6.3 (Deformation). Applying an admissible operator changes the field as follows. These rules are normative and supersede the qualitative table of earlier drafts.

  • D or J: if q > 0, q decreases by one. Unlimited quotas are unchanged.
  • A: D and J are removed from Adm, and q becomes 0. Absorption ends the capacity to branch.
  • C: S is removed from Adm. A coupled class cannot simply be suspended.
  • S: Adm becomes empty and q becomes 0. Suspension is terminal.

The quota closes a specific failure path. Coupling removes S, so without a quota a coupled class could differentiate without bound, causing a combinatorial explosion. With a quota, each region sets its own capacity for branching.

7. Fibers, Tunnels and Flux

The structures in this section give χ-RCC a concrete setting in which polarity and direction can be measured.

Definition 7.1 (Discrete fibered graph). A discrete fibered graph consists of a base b, a family of named fibers F₁, …, F_m, each a finite list of states, and the total space

E = { (Fᵢ, x) : x a state of Fᵢ }.

Every element of E projects to the base b. A set of connections ⊆ E × E says which transitions are permitted. The total space has a fixed capacity, a maximum number of elements.

This is a discrete structure. It has no local trivializations or transition functions, and it is not a differential-geometric bundle. In the reference configuration there are two fibers over one base, F_MATTER and F_ANTIMATTER. The two fibers model the two poles of a single base. This is the formal counterpart of polarity in Proto-Atomos.

Definition 7.2 (Tunnel). A tunnel is a finite sequence of elements of E in which each consecutive pair is a permitted connection. A tunnel is reentrant if it ends where it began.

Definition 7.3 (Flux). Fix a canonical orientation for each undirected edge e. Across all tunnels, let N_f(e) be the number of traversals of e in the canonical direction, and N_r(e) the number in the reverse direction. Define:

coherence κ = Σₑ |N_f(e) − N_r(e)| ⁄ Σₑ (N_f(e) + N_r(e)),
balance β = 1 − κ.

The network is balanced when N_f(e) = N_r(e) for every edge. Coherence measures net directed flow, from 0 (perfectly balanced) to 1 (entirely one-directional). These are graph measurements, not physical conservation laws.

Definition 7.4 (Directional polarity between tunnels). For two tunnels with shared undirected edges, let same count the shared edges traversed in the same direction and opposite those traversed in opposite directions. The directional polarity is

(same − opposite) ⁄ (same + opposite),

which lies in [−1, +1]. The structural overlap is the number of shared edges divided by the number of edges in either tunnel. Two tunnels with polarity −1 and overlap 1 are the same route traversed in reverse.

8. The Kernel K

The kernel K is the single authority permitted to change tunnels and constraint fields.

Definition 8.1 (Paired transition). Let τ be a tunnel ending at s, and let t be a proposed target. K admits the paired transition s → t → s only if all three conditions hold:

  • (K1) Inverse connection. Both (s, t) and (t, s) are permitted connections.
  • (K2) Admissibility. Neither s nor t is suspended, and J is admissible at s.
  • (K3) Integrity. After appending t and then s to τ, every point of every tunnel lies in E, every step is a permitted connection, the network is balanced, and the fibered graph is valid.

If all three hold, the transition is committed and χ(s) is deformed by J. If any fails, K restores the exact prior state of both the tunnels and the constraint fields. Every decision, accepted or rejected, is recorded.

The paired transition is an application of J: the system steps out to t and returns. Every change K admits is therefore a self-referential distinction.

Proposition 8.2 (Balance preservation). If the network is balanced before an admitted paired transition s → t → s with s ≠ t, it is balanced afterwards.

Proof. The transition adds exactly one traversal of the edge {s, t} in each direction. N_f and N_r for that edge each increase by one, and no other edge changes. ∎

For a self-loop (s = t), both traversals count in the same orientation, so the network becomes unbalanced and K3 rejects the transition.

Definition 8.3 (History). The record is an append-only hash chain. Each record carries the hash of the record before it:

h₀ = "GENESIS", hᵢ = SHA-256( hᵢ₋₁ ‖ recordᵢ ).

Altering any past record changes its hash and breaks every later link, so tampering is detectable. Because every admitted change is a recorded paired transition, any state can be reconstructed by replaying the record.

9. Computational Witness

The reference implementation (package chi) realizes Sections 3–8 and verifies them with a self-test.

  • Conformance. 300 recorded scenarios from the legacy implementation (version 1.12) are replayed. Decisions, history, final paths, balance and counts all match.
  • Protection. Direct changes to tunnel state are blocked. A rejected transition leaves the state unchanged. Tampering with the history is detected.
  • Constraint rules. Suspension, forbidden compositions, the differentiation quota, and full rollback of both paths and fields behave as specified.
  • Theorems. Theorems 1, 1b and 3 hold on the reference graph and on every recurrent case among 3,000 random digraphs (2 to 6 elements, edge probability 0.3, fixed seed): 2,459 recurrent cases, no counterexamples. The original, uncorrected re-entry claim fails on the two-element graph of §4.

The witness establishes that the proven results are consistent and executable. It does not test the conjectures in §10.

10. Conjectures

The results in this section were stated as theorems in earlier drafts. Their proofs are incomplete or depend on terms not yet defined, so they are offered here as conjectures.

10.1 Levels and self-similarity

Define a level hierarchy. Level 0 is (S, D). Level n + 1 takes the identity classes of level n as its elements, with a transition between two classes whenever some element of the first gives rise to some element of the second.

Observation 10.1. Under this quotient alone, the hierarchy stabilizes at once. The graph of classes is acyclic apart from self-loops on recurrent classes, so every class at level 1 is already its own identity class, and level 2 is identical to level 1. Any structure at higher levels must therefore come from operator activity, above all from C, which creates new mutual reachability between classes.

Conjecture 1 (Structural self-similarity). In hierarchies generated by operator activity, each level (Sₙ, Oₙ, χₙ) is structurally isomorphic to level 0 up to relabeling and granularity. If so, lifting is an endofunctor on the category of constraint systems.

10.2 Phase classification

Define three conditions:

  • C1: only finitely many C and S events occur across all levels;
  • C2: beyond some level, no C event adds new dependency structure to the constraint field;
  • C3: suspension is permanent, so no operation restores admissibility to a suspended region.

Conjecture 2 (Collapse). A system satisfying C1, C2 and C3 converges to a unique constraint geometry χ* that is invariant under lifting.

Each failed condition names a way the system can remain open:

  • χ-ergodic: all three hold; the system converges to χ*.
  • χ-creative: C1 fails; new phases keep being generated.
  • χ-expansive: C2 fails; coupling density grows without bound.
  • χ-regenerative: C3 fails; suspended regions can return.

10.3 Recovery

This program needs two rates to be defined: r_χ, the rate at which the constraint field deforms, and r_SCC, the rate at which identity classes form.

Conjecture 3 (Recovery modes). When r_χ exceeds r_SCC, exactly four structurally distinct recovery modes exist:

  • Freeze: reduce r_χ;
  • Restrict: shrink the domain;
  • Couple: anchor to an external system;
  • Accelerate: raise r_SCC.

Restricting forecloses accelerating.

Conjecture 4 (Attractor). Coupling combined with acceleration (C·A) is the unique non-degenerate stable configuration: the only one that keeps full generative capacity without permanent restriction or freezing.

10.4 The invariant

Conjecture 5 (Realizability). For a continuous extension of the calculus, let F map states to their induced constraint fields, and let G map constraint fields to state dynamics. The system is χ-RCC-realizable if and only if the Jacobian of the coupled map (F, G) has full rank: state evolution and constraint evolution are locally invertibly coupled. The rank of this Jacobian would then stratify the regimes of §10.2.

Conjecture 5 needs a differentiable model, which the discrete calculus does not yet supply. Building that model is an open problem.

11. Relation to the Companion Works

Book 0, The Emergence of Identity, presents the content of Sections 2–4 and §10.1 as philosophical prose. Its formal notes refer to Theorem 1 (Re-entry), Theorem 1b (closed recurrent classes), and Theorem 3 (observation as fixed point) as revised in this edition.

Proto-Atomos uses the calculus as one formal lens:

  • The self-referential distinction Δ = Δ corresponds to A2, made constructive by J.
  • The two limits of a quality correspond to two fibers over one base.
  • Pendulation corresponds to directional flux.
  • Lifting corresponds to the level hierarchy of §10.1.
  • The interior observer corresponds to A1 together with Theorem 3.

The calculus supports those works at the level of structure. It does not establish their philosophical or physical claims, which stand on their own terms.
