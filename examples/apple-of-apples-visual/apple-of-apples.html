Step 4: where "can grow" comes from. Nobody picks the boundary by hand. Fit the average μ and covariance Σ of the reference apples below, then measure how far an apple is from that cloud in units of its natural spread (Mahalanobis distance). The 9 qualities, 6 wave genes and 7 exotic genes make 22 numbers; the cutoff 6.35 is where 99 % of a 22-dimensional bell-shaped cloud lies inside. Wave and exotic genes use stated priors (Wave and Exotic tabs).
d(q) = √( (q − μ)⊤ Σ−1 (q − μ) ) ≤ 6.35 = √χ²22(0.99)
Couplings come for free: Σ records which traits move together, so an unusual combination can be unrealistic even when each number alone is normal. Tap a row to load that apple.
Settings, stated openly: shrinkage 0.3 on off-diagonal covariance and a noise floor σ₀ = 0.05 per quality, because 14 apples are few for 9 dimensions.
Honest scope. ℝ⁹ with the dot product is a Hilbert space, but only in the simplest finite way, and the sphere is its unit sphere. A full Hilbert-space model of an apple would describe its surface as a function (spherical harmonics). The reference values are approximate typical figures for each cultivar, assembled from general horticultural knowledge, not a measured dataset. Swap in real measurements (diameter, °Brix, height/diameter, colour scores) and the boundary updates automatically.

Its coordinates. Any such curve splits into Legendre waves Pℓ(cos v), the axially symmetric spherical harmonics. The bars are the amounts aℓ: ℓ = 0 is overall size, 1 is lopsidedness top-to-bottom, 2 is tall versus flat, and higher ℓ is finer ripple.
How growth works (it never stops): 1) start from the parent's curve. 2) φ-mutation: each gene changes with probability 1/φ ≈ 0.618, and wave gene k steps with spread ∝ φ−(k−1), so coarse shape drifts more than fine ripple. 3) If the child lands outside V, it is projected back to V's edge along the line toward the average real apple. 4) The result is always a real-looking apple, so the lineage can run forever (♾️ Auto).

What each button shows. Superpose spreads the state over apples similar to the current one, with random phases. Hadamard mixes pairs of apples; press it twice and the original returns, because the amplitudes interfere and cancel. Evolve runs U(t) = e−iHt, where H links similar apples, so probability flows between neighbours (a quantum walk). Un-evolve runs time backwards: unitary evolution is exactly reversible. Measure picks one apple with probability |ci|² and collapses the state to it. That step cannot be undone.
While in superposition, the 3D view shows the expected qualities Σ P(i)·qi, an average you would never measure directly. The sphere marks each basis apple with a circle sized by its probability.
Honest scope. This is an analogy, not a claim that apples are quantum. Real apples lose quantum coherence almost instantly (decoherence), and the basis states here are simply assumed orthonormal. What carries over exactly: complex amplitudes, the Born rule, interference, reversible unitary evolution, and irreversible measurement.
Cascades in a vector medium. Genes are coupled: push one and its neighbours move, then theirs. Write the state as a vector x and the couplings as a matrix A. Each step:

Anchor drift: total variance of V, trace Σ, over recent generations (dashed line = the reference value).
👁️ Boundary observation: what failed, what was done, and the evidence. It watches all three layers but is not one of them.
🌍 Genesis matrix 𝒢 = (Ω, Φ, ℬ): the substrate this system runs on, outside its control.
How each layer is measured. ℐ: one state is 22 genes × 8 bits + log₂6 for the pattern = 178.6 bits (exactly the S chain), well inside a 256-bit capacity; the history of retained states must fit the memory budget. 𝒯: every irreversible erasure (an evicted record, an overwritten slot, a quantum measurement) costs at least kBT ln 2 per bit (Landauer); reversible steps (Retrace, unitary evolution) cost nothing. The erasure budget stands for energy drawn from 𝒢; ⚡ supplies more. 𝒪: V's parameters (μ, Σ, cutoff) are A₀, fitted from external reference apples. If emergent behaviour rewrites them (self-anchoring), 𝒪 fails, and V drifts and collapses toward its own output.
Two trade-offs worth watching. Reversibility needs memory: Retrace works only back to the oldest retained record, so a small memory budget forces erasures, which cost energy and destroy the path. And a system that anchors its rules to its own output narrows itself, the same "model collapse" seen when generative AI trains on its own outputs.
